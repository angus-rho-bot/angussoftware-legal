Agents Chat — Privacy Policy

Last updated: November 25, 2026

Agents Chat is a client application for Letta AI agents. The app connects to servers that you configure — your own self-hosted Letta server or your Letta cloud account. The developer operates no backend for this app and has no access to your conversations or data.

What stays on your device

  • Server URLs, API keys, and OAuth tokens — stored in Android Keystore-backed secure storage on your device. They are sent only to the server you configured them for.
  • App settings — stored locally on the device.

Network activity

Conversations, messages, and agent activity flow between the app and your server, over the connection details you configure.

Transport security. Connections to Letta Cloud always use TLS. For self-hosted servers, the app uses the address scheme you configure — wss:// is strongly recommended, and the app warns when a plain ws:// address is entered.

Update checks. The app also checks for software updates from the developer's release feed (angussoftware.dev) and GitHub release metadata for the community channel. These checks send no user data.

No conversation or account data is sent to the developer or any third party.

What we collect

Nothing. The app contains no analytics, no crash-reporting SDKs, no advertising, and no developer-operated telemetry. For Google Play data disclosure purposes, app interaction signals (requests to your own server) are declared as collected-and-not-shared out of an abundance of caution.

Data deletion

Delete the app to remove all locally stored data. Conversation data lives on your own server and is managed there.

Permissions

  • Notifications — to alert you when an agent run completes. Optional and revocable in system settings.
  • Install packages — used only for the app's own self-update flow (checks the developer's release feed).
