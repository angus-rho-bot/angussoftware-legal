Agents Beamdown — Privacy Policy

Last updated: October 3, 2026

Agents Beamdown is an Android application (phone and Wear OS watch) that runs an AI agent runtime — a full Linux environment with the Letta Code agent server — directly on your device. This privacy policy describes how the app handles your data.

What We Do NOT Collect

Angus Software does NOT operate any server that receives your data. The app contains no analytics, no tracking, no advertisements, and no telemetry back to us. We cannot see your device, your agent, or anything it does.

Where Your Data Goes

Your data stays in two places, both under your control:

  • Your device: the agent runtime, its files, and its memory are stored locally in the app's storage.
  • Your chosen AI provider: to run the agent, you supply your own API key for a model provider of your choice (for example, z.ai or Letta Cloud). Prompts and agent activity are sent directly from your device to that provider, encrypted, under that provider's own privacy policy. We never see or relay this traffic.

Optional Device Data (Consent-Gated Telemetry)

The app can expose selected device data to your own agent — never to us. Every channel is off by default and requires an explicit in-app grant:

  • Health data (heart rate, steps, sleep, skin temperature): read on demand via Health Connect (phone) or Health Services (watch). Your agent can query readings only after you grant access per type; you can revoke at any time in system settings.
  • Location: approximate device location, readable by your agent only after you grant location permission. Revocable at any time.
  • Notifications: with a notification-listener grant, your agent can see notification titles and app names. Message content is only visible in the active screen session while you are using the device — it is never stored or transmitted by the app itself.
  • Screen control (accessibility service): with the accessibility grant, your agent can read what is on screen and tap, swipe, and type on your behalf. A persistent system indicator shows when it is active; revoke any time in Settings > Accessibility.

None of this data leaves your device unless you (or an agent acting on your instructions) explicitly send it somewhere. There is no background collection, no periodic sampling, no upload.

App Updates

The app checks for updates by fetching a version file from dl.angussoftware.dev. This check reveals your IP address to our static file server (standard web request) but carries no identifier, no device fingerprint, and no usage data. Nothing is logged beyond routine server operation.

Third-Party Services

  • Model providers (your choice): see their policies for how prompts are handled.
  • Bundled open-source components: the app embeds a Linux runtime and Node.js; these run entirely on your device.

Data Deletion

Uninstalling the app removes the runtime, the agent environment, and all locally stored data. Telemetry grants are revoked automatically when the app is uninstalled.

Children's Privacy

Agents Beamdown is a developer tool intended for adults. We collect no data from anyone.

Changes to This Policy

We may update this privacy policy from time to time. Changes will be reflected on this page with an updated revision date.
