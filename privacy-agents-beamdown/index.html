Agents Beamdown — Privacy Policy

Last updated: October 3, 2026

Agents Beamdown is an Android application (phone and Wear OS watch) that runs an AI agent runtime — a full Linux environment with the Letta Code agent server — directly on your device. This privacy policy describes how the app handles your data.

What We Do NOT Collect

Angus Software operates no backend for this app beyond the static download server described under App Updates. The app contains no analytics, no tracking, no advertisements, and no crash reporting. We receive no data about your device beyond standard web requests (IP, device model in the User-Agent) to our download server.

Where Your Data Goes

Your data stays in two places, both under your control:

  • Your device: the agent runtime, its files, and its memory are stored locally in the app's storage.
  • Your chosen AI provider: to run the agent, you supply your own API key for a model provider of your choice (for example, z.ai or Letta Cloud). Prompts and agent activity are sent directly from your device to that provider, encrypted, under that provider's own privacy policy. We never see or relay this traffic.

File Access

The app requests storage access (all files on the device) during setup — this is what lets your agents read and write files, the core function. Anything in shared storage is visible to agents you dispatch: they can read, modify, and delete files in Download, Documents, DCIM, and other shared folders. Files agents write to shared storage remain after uninstall unless deleted manually. Storage access can be revoked in system settings at any time (agents will then be unable to work with files).

Optional Device Data (Consent-Gated Telemetry)

The app can expose selected device data to your own agent — never to us. Every channel is off by default and requires an explicit in-app grant:

  • Health data (heart rate, steps, sleep, skin temperature): read on demand via Health Connect (phone) or Health Services (watch). Your agent can query readings only after you grant access per type; you can revoke at any time in system settings.
  • Location: approximate device location, readable by your agent only after you grant location permission. Revocable at any time.
  • Notifications: with a notification-listener grant, the app keeps the titles, app names, and text of your most recent 50 notifications in memory (refreshed continuously while the grant is on). Your agent can read this list during a consent window you approve (up to one hour). The app itself does not write this data to disk — but your agent may store what it reads in its own on-device memory.
  • Screen control (accessibility service): with the accessibility grant, your agent can read what is on screen and tap, swipe, and type on your behalf. A persistent system indicator shows when it is active; revoke any time in Settings > Accessibility.

Consent windows grant device control for a time box (up to one hour), not only while the screen is on — approve them thoughtfully. An agent with UI control can also, in principle, navigate Android's settings and tap "Allow" on system permission dialogs — treat agent consent as you would handing the phone to a person. None of this data leaves your device unless you (or an agent acting on your instructions) send it somewhere; nothing is collected for our benefit.

App Updates

The app checks for updates by fetching a version file from dl.angussoftware.dev — on app start, after reboots, and roughly every 5 hours. This request reveals your IP address and carries Android's standard User-Agent (device model and OS version) to our static file server, like any web request. No app identifier, account, or usage data is sent. The app also contacts registry.npmjs.org (latest Letta Code version check, at most hourly) and may download runtime components from github.com when on-demand tools are installed; DNS lookups from the embedded Linux environment resolve via Google and Cloudflare public DNS.

Third-Party Services

  • Model providers (your choice): see their policies for how prompts are handled.
  • Bundled open-source components: the app embeds a Linux runtime and Node.js; these run entirely on your device.

Data Deletion

Uninstalling the app removes the runtime, the agent environment, and all app-private data (including your stored API key). Telemetry grants are revoked automatically. Files agents wrote to shared storage (e.g. Download) remain — delete manually if wanted.

Children's Privacy

Agents Beamdown is a developer tool intended for adults. We collect no data from anyone.

Changes to This Policy

We may update this privacy policy from time to time. Changes will be reflected on this page with an updated revision date.
