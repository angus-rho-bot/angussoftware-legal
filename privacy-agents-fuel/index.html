Agents Fuel — Privacy Policy

Last updated: October 3, 2026

Agents Fuel (formerly Fuel Dashboard) is a usage-tracking dashboard for AI model quotas and spending, developed by Angus Software for Android, desktop, and web. This privacy policy describes how the app handles your data.

What We Do NOT Collect

Angus Software operates no backend for this app. It contains no analytics, no tracking, no advertisements. We never see your usage data, your API keys, or your spending.

Where Your Data Goes

  • Your device: API keys are stored in the Android Keystore (mobile) or Java Preferences (desktop); usage history lives in a local SQLite database; settings stay in local storage. Nothing leaves the device except the provider calls below.
  • Your AI providers, directly: to display quota and usage, the app calls your providers' APIs (for example z.ai or Letta Cloud) from your device, using API keys you supply. Requests go directly to those providers under their policies — we are not a party to them.

API Keys

Provider API keys are stored in your device's local storage and used only to query that provider's API from your device. Keys are never transmitted anywhere except to their own provider, never logged to any server we operate, and can be removed at any time in Settings.

Optional Features

  • Issue reporting: if you configure a Forgejo API token, the in-app "Report an issue" feature creates issues on the Angus Software issue tracker using your token. The report content is what you type; nothing else is attached.
  • Letta usage metering (optional): if enabled, the app calls the Letta API to read your own usage numbers. Only enabled if you turn it on.
  • Local server & sync: the app runs an API server on your device (localhost by default) and can sync settings to your own mobile device over your LAN (opt-in) or by QR code. No cloud copy of anything exists.

Data Deletion

Uninstalling the app (or clearing app data) removes all locally stored keys, settings, and history.

Children's Privacy

Agents Fuel is a developer tool intended for adults. We collect no data from anyone.

Changes to This Policy

We may update this privacy policy from time to time. Changes will be reflected on this page with an updated revision date.
